# Kája Project

## Overview
Kája is a desktop application designed to automate requests to OpenAI's API and process the responses efficiently. It provides a detailed control panel for users to set expectations, inputs, modes, models, and response processing.

## Features
- Automated requests to OpenAI
- Detailed logging
- Responsive UI
- Secure data handling

## Installation
1. Ensure Python 3.9 is installed.
2. Install required packages:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python ui_main.py
   ```

## Configuration
- API keys are stored in system environment variables.
- Configuration settings can be adjusted in `config/settings.json`.

## Usage
- Launch the application and enter your OpenAI API key.
- Configure your request settings and execute requests.
- View and process responses directly in the application.
