# Font assets

Place `montserrat_regular.ttf` and `montserrat_bold.ttf` (Montserrat Regular + Bold) in this folder so `main.py` can register them. Download the official releases (for example from `https://fonts.google.com/specimen/Montserrat`) and name the files as above. The app logs a warning and continues in degraded mode when the fonts are missing or invalid.
